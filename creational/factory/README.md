# Factory (JavaScript)

[Java versiyasi](../../../creational/factory) ning JavaScript varianti. Asl loyihada bu papka hali faqat boshlang'ich nuqta: `Main` "Factory" so'zini chiqaradi, xolos. Shu holat o'zgartirilmay ko'chirildi.

Factory patterni haqida tushuntirish va ishlaydigan JavaScript namunasi: [umumiy qo'llanma](../../00-GENERAL-GUIDE/README.md#2-factory).

## Fayllar

```
src/
  Main.js
```

## Ishga tushirish

Shu papkadan (Node.js 18+):

```bash
node src/Main.js
```

Natija:

```
Factory
```
